# 🎵 CodeAlpha Task 4 – Music Player

A modern, responsive and interactive **Music Player Web Application** developed as part of my **CodeAlpha Frontend Development Internship**.

The project is built using **HTML, CSS and JavaScript** and provides a smooth music-listening experience with essential audio controls, playlist management, progress tracking, volume control and a modern responsive interface.

## 📌 About The Project

This project was developed for **CodeAlpha Frontend Development Internship – Task 4**.

The objective was to create a functional music player interface using HTML and CSS, and implement audio functionality using JavaScript.

The application allows users to:

- Play and pause songs
- Move to the next or previous track
- Select songs from the playlist
- Track current playback progress
- Seek through a song
- Control volume
- Enable shuffle mode
- Enable repeat mode
- View song title and artist
- Display animated album artwork
- Use a responsive interface across different screen sizes
